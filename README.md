# THE LAST SIGNAL (3D Browser Horror) — GitHub Pages

A complete, playable first-person horror game built with **Three.js** (no backend, no paid APIs).

## ✅ Features
- Pointer-lock FPS controls (WASD, Mouse, Shift, Ctrl crouch)
- Flashlight with visible cone beam + battery meter (F)
- Cinematic lighting, deep fog, flickering emergency/fluorescent feel
- Detailed small level (rooms: checkpoint, lab, medical, generator, storage/lockers, office, exit)
- Keys, locked doors, interactive switches, readable notes
- Inventory + batteries
- Monster AI:
  - patrol → investigate suspicious sounds → line-of-sight chase → search
  - no teleporting near player
  - hiding spots require flashlight off

## 🧠 Controls
- **WASD**: move  
- **Mouse**: look  
- **Shift**: sprint  
- **Ctrl**: crouch  
- **E**: interact  
- **F**: toggle flashlight  
- **Esc**: pause / release mouse
